# 旅遊產業日語（115-1 進修部）課程教材

観光発信のための日本語 ── 台湾の「当たり前」を日本語で伝える

單頁課程網站，直接開啟 `index.html` 即可使用，也可透過 GitHub Pages 發布給學生。

## 內容

| 章節 | 對應週次 |
| --- | --- |
| 課程目標（中・日對照） | W1 |
| 18 週進度（自動標示本週） | 全學期 |
| 言い換え三大公式 | W2 |
| オノマトペ（擬聲擬態語） | W2 |
| 四大文化發信模組（街頭移動／庶民飲食／生活節奏／信仰日常） | W4 |
| 士林夜市踏查：找不同・找疑問・找安心、同理心地圖 | W4–W5 |
| Podcast 腳本模板與轉譯歷程對照表 | W6–W9 |
| 簡報發表句型、隱藏預備頁面 | W11–W13 |
| QA 應變：拖延神句、確認句、聽眾任務卡 | W12–W17 |
| 評分標準（期中 Podcast／期末提案） | W9、W16–17 |
| Can-do 自我檢核（存在學生自己的瀏覽器） | W18 |

日語例句旁的 ▶ 按鈕使用瀏覽器內建語音朗讀（建議 Chrome / Safari）。

## 修改內容

詞彙、例句、週次等資料集中在 `index.html` 下方 `<script>` 內的陣列（`SCHEDULE`、`ONO`、`MODULES`、`ROLES`、`CANDO`），直接修改文字即可。
